## Getting Started

### Claude
```bash
cd claude
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Add your API key to a `.env` file inside `claude/`:
```
ANTHROPIC_API_KEY=sk-ant-...
```
